1. In the sentence below, put in the necessary code that would allow
users to click on the word Google and open Google's homepage in a new
browser (hint: wrap google in code):
Google is the best search engine in the world.

To create a link in a html document, you start with the <a> tag. then the href is where you put the specific website you want it to take you to. then you would set target="_blank", which is what makes it link to a new tab or window instead of changing the page you are currently on. After closing the <a>, you type which word you want the link to be attached to, in this case: Google. Then close the <a> tab with </a>.
All of this would look like this:
<a href="https://www.google.com" target="_blank">Google</a> is the best search engine in the world.

10. Why do we use media queries?

A media query is a CSS code that allows us to see webpages on different devices and what they would look like. We use them so that the website layout is adjusted to whatever device the user is looking at it on.

11. What is the main difference between a serif and a sans-serif font?

Serif fonts have decorative additions to them, while sans-serif means without. A common serif font is Times New Roman, while a sans-serif would be Arial. We use the two depending on what image or branding we want to project on our webpages.

12. Which of the following is a hexadecimal code?
1. #FFCC33
2. 123,543,242
3. 101010101
4. -213


Number 1 is the hexadecimal code. These codes correspond with a certain color on the colorwheel, and are used in stylesheets to color something on your webpage. They begin with a # and have 6 digits or numbers.
